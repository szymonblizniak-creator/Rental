Ikony aplikacji

Chrome na Androidzie potrzebuje ikon PNG, żeby zainstalować aplikację jako pełnoprawną. Wygeneruj je tutaj, wprost w telefonie.

  1. Pobierz oba pliki — trafią do Pobrane
  2. Wejdź na github.com do swojego repozytorium
  3. Add file → Upload files, wybierz oba PNG, Commit changes
  4. Odczekaj minutę i odśwież aplikację
